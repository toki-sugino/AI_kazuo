# AIカズオ（劇用・しゃべるAI画面）

演者がマイクにアドリブでしゃべると、画面の中の「AIカズオ」が口を動かすWebアプリです。

- 声に合わせて口パクし、まばたきします。黙っていても、止まって見えない程度にゆれます。
- ボイスチェンジャーが入っています（AIの声・高い声など）。
- 表情（5種類）、声の種類、画像・動画の表示、暗転から起動する演出をキー1つで切り替えられます。
- カズオと画像・動画は、それぞれ出す／出さないを切り替えられます。画像・動画は枠なしの全画面にもできます。
- **画面が2つに分かれています。** 液晶（プロジェクター）には客席用の「投影画面」を全画面で映し、パソコンの画面では「操作画面」で操作します。
- **すべて無料です。** インストールも不要で、Chrome か Edge で開くだけで使えます。

---

## 1. 開き方

### URLで開く（おすすめ）

`https://toki-sugino.github.io/AI_kazuo/` を開くと操作画面が出ます。
すべての機能（声の高さの変更を含む）を使うには、URLで開いてください。

公開の手順（最初の1回だけ）：

1. GitHub でリポジトリを開き、**Settings → General** の一番下の **Danger Zone → Change visibility** で **Public** にする
2. **Settings → Pages** を開き、**Source** を **Deploy from a branch** にする。アプリが入っているブランチと `/ (root)` を選んで **Save** を押す
3. 1〜2分待つと、画面上部にURLが表示される

### ファイルを直接開く（ネットが使えないときの予備）

`index.html` をダブルクリックしても動きます。
ただしブラウザの制限で、**声の高さの変更**は使えません（口パク・ロボット感・画像・動画などは使えます）。

## 2. 本番の機材のつなぎ方

```
[演者（舞台袖）] → マイク → [Windows PC (Chrome/Edge)] ─ HDMI → 液晶／プロジェクター（投影画面）
                              │ PCの画面＝操作画面     └ 音声ケーブル → 会場スピーカー（変えた声）
```

- マイクは、**USBマイク**か**ヘッドセット**がおすすめです。PC内蔵のマイクは周りの音を拾いすぎます。
- 演者はスピーカーからできるだけ離れてください。マイクがスピーカーの音を拾うと「キーン」とハウリングします。
- HDMIでつなぐと、音がプロジェクター側から出ることがあります。パネルの「音を出す先」で、使うスピーカーを選んでください。
- Windows の画面設定は **「表示画面を拡張する」** にしてください（**Windowsキー＋P →「拡張」**）。「複製」だと操作画面が客席に映ってしまいます。

## 3. 本番前の準備（毎回）

1. PCと液晶をつなぎ、**Windowsキー＋P →「拡張」** にする
2. URLを開き、「**マイクを使って開始**」を押してマイクを許可する
3. 操作画面の「**投影開始**」を押す → 液晶に全画面で映る
   - 初回は「ウィンドウの管理」の許可を聞かれるので「許可」を押す。その後、画面の案内どおりにもう一度押す
   - 「ポップアップがブロックされました」と出たら、アドレスバー右端から許可してもう一度押す
   - うまくいかない時は、投影画面のウィンドウを液晶側へドラッグしてクリックすれば全画面になる
4. ボタンが「● 投影中」に変わり、プレビューに同じ画面が映っていることを確認する
   - 全画面が外れてしまった時は、操作画面のボタン（「全画面にする」）を押すと戻る
5. **使うマイク** を選び、しゃべってプレビューの下の緑の棒が白い線を越えるか確認する
   - 黙っていても口が動く → 「しきい値」を右へ
   - しゃべっても口があまり動かない → マイクの「感度」を右へ、または「開きやすさ」を左へ
6. **最初はヘッドホンで**「PCから声を出す」にチェックを入れ、声の種類と音量を確認する
7. 出す画像・動画を登録しておく（→「6. 画像・動画」）。**B** で暗転して出番を待つ

- 操作画面を最小化しないでください（後ろに隠れているのは大丈夫です）。
- 操作画面を読み込み直しても、投影画面の暗転・カズオのオン/オフ・出している画像はそのまま続きます。

設定は、そのPCのブラウザに自動で保存されます。

## 4. キー操作

| キー | 動作 |
|---|---|
| 1〜5 | 表情：1 通常（腰に手）／2 笑顔（両手を広げる）／3 悩み（あごに手）／4 驚き（のけぞる）／5 断定（指さし） |
| Q W E R | 声：Q 素の声／W AIの声／E 高い声／R 高いAIの声 |
| K | カズオを出す／消す |
| F | 画像・動画を全画面にする／枠に戻す（画像・動画を出している時） |
| ← → | 前／次の画像・動画を出す |
| 0 | 画像・動画を消す |
| Space | 動画の再生／一時停止 |
| B | 暗転 ⇔ 起動演出 |
| M | ミュート（口も声も止める） |
| T（長押し） | テスト口パク（マイクなしでも動く） |

投影画面を選んでいる時にキーを押しても、操作画面で押したのと同じになります。

## 5. 声（ボイスチェンジャー）

| プリセット | 中身 |
|---|---|
| Q 素の声 | 変えない |
| W AIの声 | 声の高さはそのままで、1オクターブ下の声を重ね、ロボット感と金属感を少し足す |
| E 高い声 | 5半音上げる |
| R 高いAIの声 | 高い声に、AIっぽい響きを足す |

- それぞれのプリセットは、パネルのつまみで調整できます。調整した値は保存されます。
- 声の遅れは0.05秒ほどです。舞台袖の演者が聞いても、しゃべりにくくはならない程度です。
- 「小さい音は流さない」をオンにすると、黙っている間の雑音やハウリングを抑えられます。

## 6. 画像・動画

カズオと画像・動画の組み合わせで、画面はこう並びます。

| | 画像・動画あり | 画像・動画なし |
|---|---|---|
| **カズオあり** | 左に枠つきの画像、右にカズオ | 真ん中にカズオ |
| **カズオなし** | 真ん中に枠つきの画像 | 背景だけ |

画像・動画を出している時は、**F**（「画像を全画面」）で枠なしの画面いっぱいにできます。もう一度押すと枠に戻ります。

1. 操作画面の「画像・動画」にファイルをドラッグ＆ドロップする（または「＋ 追加」）
2. 一覧をクリックすると客席に出る。もう一度クリックするか **0** で消える
3. **← →** で前後に切り替える（全画面のまま切り替えられる。一覧の ↑↓ で順番を入れ替えられる）

動画：
- 「動画は出したら再生」がオンなら、出した瞬間に再生が始まる。**Space** で再生／一時停止
- 動画の音は **操作画面から**、声と同じ「音を出す先」に出る（投影画面の映像は操作画面の再生に合わせて動く）
- 「くり返し」「音」と音量は、動画を出している時に出る枠で変えられる
- 再生できる形式は Chrome で再生できるもの（MP4（H.264）や WebM がおすすめ）

画像・動画は **そのPCのブラウザの中にだけ** 保存されます。ネットにもリポジトリにも上がりません。
本番で使うPCで登録してください（別のPCには引き継がれません）。大きな動画はPCの空き容量を使います。

## 7. キャラの絵の仕組みと、表情の追加

キャラは、**白背景の全身画像を1枚トレースしたSVG**に、**プログラムで描いた口とまばたき**を重ねて動かしています。
口開きやまばたきの画像を別に描く必要はありません。**用意するのは、表情ごとに白背景の全身画像1枚だけ**です。

| 表情（キー） | ファイル |
|---|---|
| 1 通常 | `characters/normal.svg` |
| 2 笑顔 | `characters/smile.svg` |
| 3 悩み | `characters/think.svg` |
| 4 驚き | `characters/surprise.svg` |
| 5 断定 | `characters/assert.svg` |

表情を増やすときは、`js/settings.js` の表情の一覧と `characters/config.js` に追加します。

### 表情の画像を用意するときのコツ

- 白背景で、全身が入った画像にする（**絵が画像の端に触れないように**余白を取る）
- 色は元の色のままでよい（変換で自動的に青一色になる）
- 口の周りに手や物がかぶらないようにする（口は開いていても閉じていてもよい。変換のときに消して描き直す）
- 「通常」の絵と同じ人物・同じ画風・同じくらいの大きさにする

画像生成AI（ChatGPT や Gemini の無料版など）に「通常」の絵を渡して、たとえば次のように頼みます。

> この絵と同じ人物・同じ画風・同じ服で、白背景の全身イラストを作って。腕を組んで怒った顔。口は閉じて。

### 変換のしかた

```
pip install vtracer pillow numpy
python tools/make_character.py 元画像.png characters/angry.svg --mouth 左,上,右,下
```

1. `--mouth` に、消す口の範囲（元画像のピクセル座標）を指定して変換する
2. 表示された「肌の色」と、口の位置・まばたきの位置を `characters/config.js` に追加する（書き方は `normal` を参考にする）

口とまばたきの位置合わせは、元画像を見ながら数値を決める作業です。画像ができたら Claude に渡せば、この作業もまとめて行います。

## 8. 困ったとき

| 症状 | 対処 |
|---|---|
| 動画の音が出ない | 動画の枠の「音」と音量、声の「音を出す先」を確認する。音が出せなかったという案内が出たら、操作画面を1回クリックしてもう一度再生 |
| 投影画面が開かない | アドレスバー右端の「ポップアップがブロックされました」から許可する |
| 投影画面が液晶に出ない | Windowsキー＋P で「拡張」になっているか確認し、投影画面を閉じて「投影開始」を押し直す。だめならウィンドウを液晶側へドラッグしてクリック |
| 「投影画面：未接続」のまま | 投影画面を閉じて、操作画面の「投影画面を開く」から開き直す |
| マイクが使えない | アドレスバー左の鍵マークからマイクを「許可」にして、ページを読み込み直す |
| キーンと鳴る（ハウリング） | 音量を下げる／マイクをスピーカーから離す／「小さい音は流さない」をオンにする／「しきい値」を上げる |
| 黙っているのに口が動く | 「しきい値」を右へ／「ノイズ抑制」をオン |
| 声が出ない | 「PCから声を出す」のチェックと「音を出す先」を確認する。Mキーでミュート中になっていないか確認する |
| 口の位置がずれている | `characters/config.js` の mouth の数値を直す |

```
js/app.js                操作画面の制御とキー操作
js/screen.js             投影画面の表示
js/photos.js             画像・動画の保存（ブラウザの中）

```
