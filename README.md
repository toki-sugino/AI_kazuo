# AIカズオ（劇用・しゃべるAI画面）

演者がマイクにアドリブでしゃべると、画面の中の「AIカズオ」が口を動かすWebアプリです。

- 声に合わせて口パクし、まばたきします。黙っていても、止まって見えない程度にゆれます。
- ボイスチェンジャーが入っています（AIの声・高い声など）。
- 表情（6種類）、声の種類、暗転から起動する演出をキー1つで切り替えられます。
- **すべて無料です。** インストールも不要で、Chrome か Edge で開くだけで使えます。

---

## 1. 開き方

### URLで開く（おすすめ）

GitHub Pages で公開すると、`https://toki-sugino.github.io/AI_kazuo/` のようなURLで開けます。
すべての機能（声の高さの変更を含む）を使うには、URLで開いてください。

公開の手順（最初の1回だけ）：

1. GitHub でリポジトリを開き、**Settings → General** の一番下の **Danger Zone → Change visibility** で **Public** にする
2. **Settings → Pages** を開き、**Source** を **Deploy from a branch** にする。アプリが入っているブランチと `/ (root)` を選んで **Save** を押す
3. 1〜2分待つと、画面上部にURLが表示される

### ファイルを直接開く（ネットが使えないときの予備）

`index.html` をダブルクリックしても動きます。
ただしブラウザの制限で、**声の高さの変更**は使えません（口パク・ロボット感などは使えます）。

## 2. 本番の機材のつなぎ方

```
[演者（舞台袖）] → マイク → [Windows PC (Chrome/Edge)] → HDMI → プロジェクター/テレビ（映像）
                                     └→ 音声ケーブル → 会場スピーカー（変えた声）
```

- マイクは、**USBマイク**か**ヘッドセット**がおすすめです。PC内蔵のマイクは周りの音を拾いすぎます。
- 演者はスピーカーからできるだけ離れてください。マイクがスピーカーの音を拾うと「キーン」とハウリングします。
- HDMIでつなぐと、音がプロジェクター側から出ることがあります。パネルの「音を出す先」で、使うスピーカーを選んでください。
- 映像は **PC画面の複製**にしておくと、操作する人も同じ画面を見られて楽です。

## 3. 本番前の準備（毎回）

1. URLを開き、「**マイクを使って開始**」を押してマイクを許可する
2. パネルで **使うマイク** を選び、しゃべって緑の棒が白い線を越えるか確認する
   - 黙っていても口が動く → 「反応しきい値」を右へ
   - しゃべっても口があまり動かない → 「マイク感度」を右へ、または「口の開きやすさ」を左へ
3. **最初はヘッドホンで**「PCから声を出す」にチェックを入れ、声の種類と音量を確認する
4. **F** で全画面、**H** でパネルを隠す。**B** で暗転して出番を待つ

設定は、そのPCのブラウザに自動で保存されます。

## 4. キー操作

| キー | 動作 |
|---|---|
| 1〜6 | 表情：1 通常（ニヤリ）／2 笑顔／3 怒り／4 考え・疑い／5 困り・悲しみ／6 驚き |
| Q W E R | 声：Q 素の声／W AIの声／E 高い声／R 高いAIの声 |
| B | 暗転 ⇔ 起動演出 |
| M | ミュート（口も声も止める） |
| T（長押し） | テスト口パク（マイクなしでも動く） |
| H | 操作パネルを隠す／出す |
| F | 全画面 |

パネルを隠している間は、客席に何も表示されません。操作はキーだけで行ってください。

## 5. 声（ボイスチェンジャー）

| プリセット | 中身 |
|---|---|
| Q 素の声 | 変えない |
| W AIの声 | 声の高さはそのままで、1オクターブ下の声を重ね、ロボット感と金属感を少し足す |
| E 高い声 | 5半音上げる |
| R 高いAIの声 | 高い声に、AIっぽい響きを足す |

- それぞれのプリセットは、パネルのつまみで調整できます。調整した値は保存されます。
- 声の遅れは0.05秒ほどです。舞台袖の演者が聞いても、しゃべりにくくはならない程度です。
- 「小さい音は流さない（ゲート）」をオンにすると、黙っている間の雑音やハウリングを抑えられます。

## 6. キャラの絵の仕組みと、表情の追加

キャラは、**白背景の全身画像を1枚トレースしたSVG**に、**プログラムで描いた口とまばたき**を重ねて動かしています。
口開きやまばたきの画像を別に描く必要はありません。**用意するのは、表情ごとに白背景の全身画像1枚だけ**です。

| 表情（キー） | ファイル | 状態 |
|---|---|---|
| 1 通常（ニヤリ） | `characters/normal.svg` | あり |
| 2 笑顔 | `characters/smile.svg` | 未 |
| 3 怒り | `characters/angry.svg` | 未 |
| 4 考え・疑い | `characters/think.svg` | 未 |
| 5 困り・悲しみ | `characters/sad.svg` | 未 |
| 6 驚き | `characters/surprise.svg` | 未 |

まだ絵がない表情を選ぶと、「通常」の絵を表示します。

### 表情の画像を用意するときのコツ

- 白背景で、全身が入った画像にする（**絵が画像の端に触れないように**余白を取る）
- 色は元の色のままでよい（変換で自動的に青一色になる）
- **口は閉じた状態**で、口の周りに手や物がかぶらないようにする
- 「通常」の絵と同じ人物・同じ画風・同じくらいの大きさにする
- ポーズの目安：通常・笑顔＝腰に手、怒り＝腕組み、驚き・考え・疑い＝手もみ

画像生成AI（ChatGPT や Gemini の無料版など）に「通常」の絵を渡して、たとえば次のように頼みます。

> この絵と同じ人物・同じ画風・同じ服で、白背景の全身イラストを作って。腕を組んで怒った顔。口は閉じて。

### 変換のしかた

```
pip install vtracer pillow numpy
python tools/make_character.py 元画像.png characters/angry.svg --mouth 左,上,右,下
```

1. `--mouth` に、消す口の範囲（元画像のピクセル座標）を指定して変換する
2. 表示された「肌の色」と、口の位置・まばたきの位置を `characters/config.js` に追加する（書き方は `normal` を参考にする）

口とまばたきの位置合わせは、元画像を見ながら数値を決める作業です。画像ができたら Claude に渡せば、この作業もまとめて行います。

## 7. 困ったとき

| 症状 | 対処 |
|---|---|
| マイクが使えない | アドレスバー左の鍵マークからマイクを「許可」にして、ページを読み込み直す |
| キーンと鳴る（ハウリング） | 音量を下げる／マイクをスピーカーから離す／「ゲート」をオンにする／「反応しきい値」を上げる |
| 黙っているのに口が動く | 「反応しきい値」を右へ／「ノイズ抑制」をオン |
| 声が出ない | 「PCから声を出す」のチェックと「音を出す先」を確認する。Mキーでミュート中になっていないか確認する |
| 口の位置がずれている | `characters/config.js` の mouth の数値を直す |

## ファイル構成

```
index.html               画面とパネル
css/style.css            見た目
characters/config.js     表情ごとの絵と、口・まばたきの位置
characters/*.svg         トレースしたキャラの絵（口は消してある）
js/settings.js           初期設定（声のプリセットや表情の一覧）
js/audio.js              マイク・口パク用の音量解析・ボイスチェンジャー
js/traced-char.js        キャラの表示（口パク・まばたき・ゆれ）
js/background.js         背景（横線と舞う粒）
js/app.js                全体の制御とキー操作
tools/make_character.py  白背景の画像 → 青一色のSVG に変換するスクリプト
```
